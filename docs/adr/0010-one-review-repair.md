# 审查拒绝通过原生 Leader 循环进入一次整体返工

#26 延续 ADR 0009 的 Reviewer 与 MetaGPT 扩展点，将首次有效拒绝作为业务产物返回 Leader。只有冻结规格和当前代码的有效阻断意见可以授权一次 Engineer 返工；新代码立即失去旧审查资格，复审仍拒绝则结束。平台同时校验实际分派顺序和任务/代码身份，以避免模型重复审查、跳过交接或替换旧批准。保留每次真实交付和调用，不引入第二套顺序编排。

所有角色、一次审查格式纠正、返工及复审共享 4 分钟/20 次请求。停止关闭连接并终止受监督进程；澄清与不支持是有内容的结束状态，用户补充后新建任务，不在后端挂起。新任务的交付校验更严格，历史已保存 QA/Reviewer 记录只按其原始类型展示，不重新审查或补造。

2026-10-01：交付门槛与返工次数由 [ADR 0011](0011-review-findings-and-preview.md) 更新；原有决定和验收证据保留历史原意。
