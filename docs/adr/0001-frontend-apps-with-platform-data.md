# 首版生成轻量前端应用，由平台统一保存业务数据

2026-09-29，用户确认首版支持轻量前端应用，应用业务数据通过平台提供的固定能力保存，暂不生成任意后端程序、数据库结构或登录体系。将生成范围集中在界面和业务交互，由平台统一承担数据存取与恢复，可减少生成结果之间的保存行为差异，并控制运行环境和验收成本；代价是首版不支持需要自定义后端的应用。

这项决定限定了生成范围与数据职责；M1 的生成格式、运行方式与存储选择随后由 [ADR 0002](0002-m1-html-preview-browser-storage.md) 确定。恢复范围以 [北极星](../../NORTH_STAR.md) 的最新约定为准。它也不改变 P0 与 P1 的原有优先级。
