# 项目归属账号，云端保存支持跨设备恢复

实施规格：[邮箱验证码登录、账号私有云端项目与跨设备恢复（Issue #65）](https://github.com/lnisre/atoms/issues/65)。

2026-10-10，用户选择“每个账号拥有自己的项目并跨设备恢复”，并确认以云端保存成功为准、多设备旧版本写入拒绝覆盖、首版未采用候选与试用数据仍只保留在当前会话。选择这一边界是为了让跨设备恢复可信，同时避免首版承担任意应用业务数据的自动合并、离线双向同步与运行中任务接续。

已确认的设计边界：

- 跨设备恢复读取最近保存成功的项目内容与正式业务数据，包括已保存的待验证项目及其限制。未采用候选、试用数据及运行中任务不因此获得跨设备接续能力。
- 保存时检查读取版本；云端已有更新时拒绝旧写入，不静默覆盖或自动合并。未保存内容保留在当前页面，提供下载副本或重新载入云端版本的出口；不承诺刷新或关闭页面后恢复这些未保存内容。
- “已保存”以云端事务成功提交为依据。断网、响应丢失和登录过期时，首版提供页面内保留、重试或下载副本，同账号重新登录后可以继续处理；主动退出或切换账号前提示未保存内容。不引入本地草稿同步机制。
- 用户主要从中国大陆网络访问，优先人民币或国内支付，日常云端操作需要方便开发 Agent 使用。
- 开放注册，任何人可以注册；首版以邮箱验证码作为唯一登录方式。用户明确暂不新增生成次数配额；这不要求移除已有单任务执行时长、模型请求次数和执行器并发保护。开放注册后的总体模型费用没有新增的用户次数配额约束。
- 游客可以浏览首页并只读查看示例，不允许修改示例代码或业务数据；真实生成与账号项目的云端保存要求登录。此决定替代上一轮的游客可操作会话内示例建议，不能把仅不落盘的可编辑试用当作只读。
- 用户登录后，可通过明确的“保存此示例到我的项目”操作创建个人副本；普通登录不自动复制示例或给每个账号预置项目。游客只读，因此没有游客修改数据的迁移流程。
- 登录是明确操作的前置步骤时，成功后继续原操作，并保证只执行一次；例如游客提交需求后登录成功，继续该次生成。普通登录不触发生成；登录失败保留已填写的需求。
- 登录自然失效时，已启动的生成任务仍可在原有时长与请求预算内完成，成果保留在当前页面并绑定原账号；重新登录同一账号后再保存。自然失效不重置任务预算，也不扩大为后台续跑或跨设备接续。
- 主动退出或切换账号时停止当前任务；有未保存内容则提示并提供先下载副本的机会，确认退出后清除原账号页面状态。迟到的生成或保存响应不得进入另一账号的页面；已成功提交的云端内容不因退出而撤销。
- 首版项目为个人私有；项目链接供本人跨设备打开，不提供他人查看分享或多人协作。
- 首版账号管理仅含当前账号展示、登录和退出；修改邮箱、注销账号、项目删除独立于本次交付。
- 忽略现有浏览器本地旧项目，本轮不提供扫描、导入或自动认领流程。此决定不授权删除 IndexedDB 原件；新账号的项目列表以云端数据为准。
- 登录与云端保存独立交付；历史项目恢复继续单独设计，未来接入时历史快照与撤销状态统一归账号并存于云端。

用户接受本次采用 CloudBase 上海 PostgreSQL 与 Auth，应用继续部署在 Vercel，完整应用托管迁移另行处理。数据库管理读写、独立 Auth provider 配置和最小容器部署已有[实测证据](../verification/cloudbase-capability-2026-10-10.md)。这不等于真实登录、按用户授权或完整 Atoms 部署已验收；本次无需因登录功能另行购买域名或切换生产入口。

落地后将替代 [ADR 0002](0002-m1-html-preview-browser-storage.md) 中“仅浏览器存储、仅同浏览器恢复”的范围，并调整 [ADR 0012](0012-first-visit-example-project.md) 的本地自动预置示例边界为游客只读、登录后明确保存个人副本。这里的跨设备恢复与 另项设计中的历史项目恢复不同，两项独立交付，本讨论不覆盖历史恢复尚未完成的设计。

2026-10-10，用户完成各轮选择并同意最后三项登录续接、会话失效和账号管理边界，本决定正式接受。当前没有剩余待用户选择的产品范围；邮件送达、运行时用户鉴权与数据隔离、保存失败/冲突出口、完整生成链路和跨设备恢复属于后续实现与验收事项。本记录不表示应用代码已实现或已部署。
