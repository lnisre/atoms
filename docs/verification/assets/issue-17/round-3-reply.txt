本轮修改：在原有“减少一次”“增加一次”“增加五次”“归零”四个按钮的基础上，新增了一个“翻倍”按钮，点击后将当前 count 乘以 2，并把结果 {count:number} 通过平台 atoms.saveState 保存。

已有功能与数据格式全部保留：countValue 元素 id 不变，按钮布局仍为白底蓝字/蓝底白字的简约风格，屏幕宽度较小时按钮自动换行。新增按钮也遵循同样的可访问性处理（原生 button、键盘 Enter/Space 可触发、聚焦可见轮廓、保存期间统一禁用）。

如何使用：
1. 页面加载时会先通过 atoms.loadState 读取上次保存的数据，加载期间所有按钮为禁用状态。
2. 点击“增加一次”“增加五次”“减少一次”“翻倍”或“归零”，页面立即更新数字并显示“正在保存…”，等 atoms.saveState 的 Promise 完成后显示“已保存”。
3. 保存期间按钮暂时禁用，避免重复操作；保存失败会显示错误提示并重新启用按钮，便于重试。
4. 负数会被阻止（“减少一次”在 0 时无效果）。

浏览器保存限制：数据仅通过平台 atoms 保存在当前浏览器和当前站点下，没有后端、没有账号、没有网络同步。刷新或重新打开同一浏览器同一站点可以恢复；清除该站点的浏览器数据、换浏览器或换设备后无法找回。若平台读取失败，应用会提示错误并保持编辑禁用，不会覆盖原有数据。
