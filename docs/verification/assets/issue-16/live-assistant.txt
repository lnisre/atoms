我构建了极简中文应用“生成记录验收计数器”，白底蓝色按钮，无任何外部资源或后端。

如何使用：
- 显示区“当前次数”的数值元素 id 为 countValue，初始 0。
- 点击“增加一次”使计数 +1；“归零”将计数重置为 0。按钮支持键盘操作（Tab 聚焦、空格/回车触发），并带可见焦点样式。
- 每次添加或归零都会立即调用平台 window.atoms.saveState({count: number})，只在整个状态写入提交后才显示“已保存”。
- 页面启动时先 await window.atoms.loadState()：若返回 null，则使用默认值 0；若返回已有数据，则按 {count:number} 原样恢复（含已完成/删除等状态，这里只有计数）。若读取失败，会显示错误并保持按钮禁用，避免覆盖未读取的数据。
- 保存进行中按钮会禁用，保存失败会显示红色错误提示，可重试。

限制说明：
- 数据仅通过平台 atoms 保存在本浏览器与本站点范围内。刷新或重开可恢复，但清除站点数据、换浏览器或换设备后无法找回；没有后端、登录或云同步，因此无法跨设备或跨站点恢复。
- 界面本身已提示这一恢复限制。
- 不包含表单提交、弹窗或任何外部请求；图形均用 CSS 实现。
