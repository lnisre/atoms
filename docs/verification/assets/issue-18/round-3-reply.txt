已完成修改：在保留全部原有功能（增加一次、减少一次、增加五次、countValue 显示、白底蓝色按钮、保存状态提示、最低为 0 的限制）的前提下，新增了「翻倍」按钮。

新增交互：
- 点击「翻倍」将当前次数乘以 2。
- 翻倍与其他按钮共用同一个异步变更处理器：先更新内存与界面、同步发起 saveState 并显示「正在保存…」，等待 Promise 完成后显示「已更新（保存完成）」；若失败则回滚到原值并显示错误。
- 翻倍在次数为 0 时自动禁用；数值超过安全整数时封顶为 Number.MAX_SAFE_INTEGER，避免 JSON 精度问题。

数据与兼容：
- 数据结构仍为 {count:number}，未新增或改写字段，旧记录原样读取，不会在初始化时写入默认值。
- 读取失败或数据格式无法识别时，编辑保持停用，不覆盖已有数据。

使用方式：页面加载后先读取已保存数据，读取完成后按钮启用；点击任一按钮即执行对应运算并等待保存结果。

限制说明（已在页面内注明）：数据仅保存在当前浏览器与本站点，无后端、登录或外部服务；恢复范围仅限本浏览器与本站点，清除站点数据后无法找回。
