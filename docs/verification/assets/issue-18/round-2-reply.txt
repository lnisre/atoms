本轮修改说明

1) 标题改为「工作台多轮验收」（<title> 与页面 h1 同步）。
2) 新增「增加五次」按钮（id=addFiveButton，type="button"），点击一次计数加 5。
3) 保留原有全部功能：显示元素 id=countValue、「增加一次」加 1、「减少一次」减 1 且最低为 0，数据结构仍为 {count:number}。
4) 旧业务数据（count）原样恢复，不自动写入默认值；仅当 loadState() 返回 null 时使用默认值 {count:0}，且初始化阶段不保存。

使用方式
- 打开后先等待读取：显示「正在读取已保存的数据…」，读取成功后才启用按钮。
- 点击任一按钮：立即更新数字，同步调用 window.atoms.saveState(snapshot)（在同一事件处理器内、任何 await 之前发起），界面显示「正在保存…」，Promise 解析后显示「已更新（保存完成）」。
- 保存失败会回滚到本次点击前的计数并显示错误；读取失败时保持只读且不覆盖既有数据。
- 键盘：三个按钮均可 Tab 聚焦，Enter/Space 触发（浏览器默认按钮行为），带 focus-visible 焦点样式。布局为响应式，窄屏纵向排列、宽屏横向排列。

实际限制（诚实说明）
- 本应用无后端、无登录、无外部服务，所有业务数据仅通过平台提供的 window.atoms.loadState()/saveState() 存取；我未运行任何测试或工具，上述行为基于代码逻辑。
- 数据恢复范围限于本浏览器与本站点（站点数据保留期间）；更换浏览器或清除站点数据后无法恢复。
- 我无法在本应用内访问网络、存储 API 或父页面；若平台存储失败，只能显示错误并回滚，无法在其他位置备份。
- 若已存在数据格式无法识别（count 非有限数值），为防覆盖会保持只读并提示。
