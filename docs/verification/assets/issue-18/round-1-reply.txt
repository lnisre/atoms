本轮变化：在保留原有「增加一次」按钮、id=countValue 以及 {count:number} 数据格式的前提下，新增了「减少一次」按钮，每次点击减 1，最低为 0（到 0 时自动禁用减少按钮）。

实现要点：
- 启动时先 await window.atoms.loadState()，读取完成前所有按钮禁用；读取失败或数据格式不可识别时，显示错误并保持编辑停用，绝不覆盖已有数据。
- 旧业务数据原样恢复：只要已有数据的 count 是有效数字就照原值显示，不会在初始化时自动写入默认值；只有 loadState() 返回 null（全新项目）时才使用默认值 0，且不立即保存。
- 增加和减少共用同一个异步变更处理器：先在内存中更新状态并渲染，随后同一事件处理器内立即调用 saveState(snapshot)，再 await 其完成；成功后显示「已保存」，失败时回滚计数并显示错误。保存期间按钮短暂禁用，避免重叠保存。
- 键盘与无障碍：按钮为标准 type="button"，可用 Tab 聚焦、Enter/Space 触发，countValue 使用 aria-live 提示更新，状态栏 role="status"。

使用方式：待「正在读取已保存的数据…」消失后，点击「增加一次」或「减少一次」即可。计数最低为 0，减少按钮在 0 时不可用。

限制说明：数据仅保存在本浏览器与本站点范围内，没有后端、登录或外部服务，换浏览器或清除站点数据后无法恢复；平台会显示当前存储模式（试用或正式）。应用本身不做任何联网请求，也不使用 localStorage 等其它存储。
