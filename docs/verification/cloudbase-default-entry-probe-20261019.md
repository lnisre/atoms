## 授权与用途

2026-10-19，用户明确将当前目标调整为：先通过 CloudBase 自动分配的默认 HTTPS 域名交付给少量受邀者临时内测；购买和备案自定义域名不作为本轮临时云端测试前置。它不等于将默认域名作为正式生产或大规模分发入口。

重新读取[官方默认域名规则](https://docs.cloudbase.net/service/alias)及其 Markdown：开发测试访客按风险提示正常点击“确定访问”，Cookie 有效期内同域名不重复提示；有效期动态调整。默认域名仍可能受风控。本轮使用真实浏览器导航和正常倒计时按钮，没有伪造安全头、设置平台确认 Cookie 或绕过中间页。
