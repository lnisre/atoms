## 失败与修正

第一轮接口请求约 13.21 秒后返回 502：模型在完整 HTML 文档前后添加了解释和 Markdown 围栏，严格格式检查拒绝了产物。浏览器同时显示错误并可重试，没有伪造成功。随后改为只提取唯一完整文档，不修补代码，不补齐截断输出，并加入对应测试。修正后重新构建、本地与线上真实生成通过。

初次浏览器回归中 3 项断言同时匹配了应用提示与 Next.js 的空路由播报节点。将定位范围限定在应用 main 后，5 项测试全部通过；这不是业务错误被隐藏。

初次生产构建受执行沙箱端口限制而失败；允许本地编译子进程端口后，同一构建命令通过。线上 Vercel 构建也独立通过。

Vercel 凭据文件使用 `VERCEL_TOKEN=...` 格式。首次误将整行作为 token 导致认证失败，按正确格式解析后恢复访问；创建新项目权限不足，用户随后明确授权使用 v0-test0 并确认框架、Node.js、Fluid compute、生产环境变量和内容替换。生产配置和部署已完成。
