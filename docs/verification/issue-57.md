## 本票行为

- 保存失败但完整成果留在页面时，右侧两种视图均明确提示未保存、刷新或离开无法恢复，并引导复制原始源码。待验证成果不再虚称“代码与问题已保存”；未保存时禁用“使用此版本”，处理函数也检查保存状态。
- 执行阻断原因在源码模式仍可见，明确只读可复制、暂不可采用；左侧首次结果卡及任务提示不再引导运行被禁止的成果。原有禁止挂载 iframe 的条件未变。
- 提示支持换行及区域内滚动，避免长原因挤占整个成果区。工作台保持左右布局，窄窗口仍由既有查看器优先收起目录。
- 沿用存储层的 `draftResult` 显示映射，恢复的是原始代码而非旧客户端兼容说明页。没有迁移存储、修改生成协议或新增生产 API。
- 沿用项目身份重建查看器、会话内阅读偏好和原子采用规则。刷新、重开及项目切换默认预览，再进入代码打开入口；试用数据不随采用写回正式数据。
- 修改阶段的执行阻断仍在创建候选之前失败；不额外保留该次源码。首次无完整产物仍禁用代码入口，项目读取错误仍明确报错，未伪装为空成果。

最后两项中的生成/停止/迟到响应完整矩阵沿用既有门槛，仅做静态核对和复用已有证据；本票没有将其完整重跑。

| --- | --- |
| 首次禁止运行成果 | 实际保留的 `draftResult.html` 与显示/剪贴板逐字符一致，数据库 `result.html` 仍是兼容页；首次、刷新及重开均无 iframe、无使用入口，代码模式显示限制 |
| 首次审查未完成成果 | 恢复原始待验证代码，搜索和复制正确；已保存时原有“使用此版本”仍可用；未因阅读自动采用 |
| 首次待验证保存失败 | 新项目真实写入失败后，代码可搜索并复制原文，右侧明确未保存，不能使用此版本；刷新后项目未出现在已保存列表 |
| 多轮采用及采用失败后重开 | 两轮采用后恢复最新已保存代码；候选试用值未写回正式数据；第三轮采用事务中止后，本页仍可复制候选，关闭重开只恢复第二轮代码及正式数据 |
| 读取失败 | 持续读取故障明确报错，无“空项目”或空源码假象；恢复读取并点击重试后默认预览，可查找复制此前已保存代码 |
| 合成版本更新 | 搜索存在时手动滚动，更新同路径内容后保留选择、目录及横纵位置；匹配重新计算，复制成功反馈按版本清空，新复制内容准确；缩短后位置有效 |
| 合成文件移除 | 当前路径消失回到新入口并解释；移除目录/滚动状态不会在重加时复活 |
